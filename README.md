# React + Vite

## Description

This project is a template for setting up a React application using Vite. It includes hot module replacement (HMR) for a smooth development experience and some basic ESLint rules to maintain code quality. The template supports two official plugins for React: one using Babel and the other using SWC for fast refresh.

## Features

- Minimal setup to get started with React and Vite
- Hot Module Replacement (HMR) for a better development experience
- Basic ESLint rules for code quality
- Support for Babel and SWC plugins for fast refresh

## Available Plugins

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh

## Getting Started

To get started with this project, clone the repository and install the dependencies:

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
npm install
```

Then, start the development server:

```bash
npm run dev
```

Open your browser and navigate to `http://localhost:3000` to see the application running.
